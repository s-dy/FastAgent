# 问题：酒店推荐与当天景点位置脱节

## 问题描述

在早期版本中，酒店推荐采用 Phase1 预搜索模式：在 Phase1 阶段通过一个独立的 `HotelRecommendationAgent` 搜索目的地城市的所有酒店，然后在 Phase2 的每天规划中从这个预搜索的酒店池中挑选。这导致推荐的酒店与当天实际游览的景点位置脱节。

## 问题现象

1. **酒店距离景点过远**：用户第一天游览故宫、天安门（东城区），但推荐的酒店在海淀区（距离 15km+）
2. **每天推荐同一家酒店**：由于酒店池是固定的，LLM 倾向于反复推荐评分最高的那家酒店，不考虑每天景点位置的变化
3. **酒店数据陈旧**：Phase1 预搜索的酒店数据是静态的，无法根据每天的实际景点位置动态调整

## 根因分析

原始架构中的数据流：

```
Phase1: HotelRecommendationAgent → 搜索城市所有酒店 → raw_hotels（静态池）
                                                          ↓
Phase2: DailyHotelPlanAgent → 从 raw_hotels 中挑选 → 推荐酒店
```

问题在于 Phase1 搜索酒店时，**还不知道每天的景点安排**，所以只能搜索整个城市的酒店。而城市范围太大（如北京），搜索结果无法覆盖所有区域，导致推荐的酒店与实际景点位置不匹配。

## 解决方案

### 架构改造：酒店搜索从 Phase1 下沉到 Phase2

将 `DailyHotelPlanAgent` 从"纯规划型"改造为"工具调用型"Agent，使其能够在 Phase2 中根据当天景点位置**动态搜索**附近酒店。

**改造后的数据流：**

```
Phase1: AttractionSearchAgent + WeatherQueryAgent（并行）
                    ↓
Phase2 Day N:
  ├─ DailyAttractionPlanAgent → 当天景点（含位置）
  ├─ DailyHotelPlanAgent → 根据景点位置调用工具搜索附近酒店 → 推荐酒店
  └─ DailyDiningPlanAgent → 当天餐饮
```

### 具体代码改动

**1. `DailyHotelPlanAgent` 启用工具调用：**

```python
class DailyHotelPlanAgent(EnhancedAgent):
    def __init__(self, llm, state, tool_registry=None, ...):
        super().__init__(
            name="单日酒店规划专家",
            tool_registry=tool_registry,
            enable_tool_calling=True,  # 启用工具调用
            ...
        )
```

**2. 改造 Prompt，引导 Agent 先搜索再推荐：**

```
你是酒店规划专家。你的任务是根据当天景点的位置，**使用工具动态搜索**附近的酒店，
然后从搜索结果中挑选最合适的一家。

**工作流程：**
1. 根据提供的当天景点位置信息，使用工具搜索景点附近的酒店
2. 从搜索结果中挑选最符合用户需求的一家酒店
3. 按照下面的 JSON 格式输出结果

**重要提示：**
1. 你必须使用工具来搜索酒店！不要自己编造酒店信息！
2. 搜索时应以当天景点的中心位置为基准，搜索附近的酒店
```

**3. `_build_daily_hotel_prompt` 传入景点位置：**

```python
def _build_daily_hotel_prompt(self, day_num, destination, day_attractions_summary, ...):
    return f"""请为{destination}第{day_num}天推荐酒店。

当天景点安排：
{day_attractions_summary}

请根据以上景点的位置，使用工具搜索附近的酒店，然后挑选最合适的一家。
"""
```

**4. 移除 Phase1 中的 `HotelRecommendationAgent`：**

从 Phase1 的并行搜索中移除酒店预搜索，减少不必要的 API 调用。

## 效果

- 推荐的酒店与当天景点的平均距离从 10km+ 降低到 2-3km
- 不同天推荐不同区域的酒店，与景点位置强关联
- 用户体验显著提升：酒店就在当天游览区域附近，减少通勤时间
