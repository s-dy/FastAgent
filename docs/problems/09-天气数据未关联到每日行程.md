# 问题：天气数据未关联到每日行程，DailyPlan.weather 始终为 None

## 问题描述

系统在 Phase1 通过 `WeatherQueryAgent` 查询了行程期间的天气预报，天气数据也作为文本传递给了 Phase2 的景点规划 Agent（用于雨天优先室内景点）。但最终返回给前端的 `DailyPlan` 对象中，`weather` 字段始终为 `None`，用户在行程详情页看不到每天的天气信息。

## 代码层面的根因

### 1. DailyPlan 组装时 weather 硬编码为 None

在 `planner.py` 第 768-776 行，组装 `DailyPlan` 时 `weather` 字段被硬编码为 `None`：

```python
daily_plan = DailyPlan(
    day=day_num,
    theme="",
    weather=None,  # 始终为 None！
    hotels=hotels,
    attractions=attractions,
    dining=dining,
    budget=daily_budget,
)
```

### 2. 天气数据只作为文本传递，未被结构化解析

Phase1 的 `WeatherQueryAgent` 返回的是自然语言文本（`raw_weather`），这段文本被直接传入 Phase2 景点规划 Agent 的 Prompt 中作为参考。但系统从未将这段文本解析为结构化的 `WeatherInfo` 模型。

### 3. WeatherInfo 模型已定义但未使用

`common.py` 中已经定义了完整的 `WeatherInfo` 模型：

```python
class WeatherInfo(BaseModel):
    date: str
    day_weather: str
    night_weather: str
    day_temp: int
    night_temp: int
    wind_direction: str
    wind_power: str
```

`DailyPlan` 模型中也声明了 `weather: Optional[WeatherInfo]` 字段，但从未被赋值。

## 影响范围

- 前端行程详情页无法展示每天的天气信息
- 用户无法根据天气提前准备（如带伞、防晒等）
- `WeatherInfo` 模型的 `field_validator` 等精心设计的容错逻辑从未被触发

## 解决方案

### 方案：在 Phase1 后解析天气数据，Phase2 组装时关联

**步骤 1**：在 Phase1 完成后，将天气文本解析为结构化数据

可以新增一个方法 `_parse_weather_data()`，使用 LLM 或正则表达式将天气文本解析为 `WeatherInfo` 列表：

```python
def _parse_weather_data(self, raw_weather: str, start_date: str, duration: int) -> Dict[int, WeatherInfo]:
    """将天气文本解析为按天索引的 WeatherInfo 字典"""
    # 方案 A：让 WeatherQueryAgent 直接输出 JSON 格式
    # 方案 B：用正则从文本中提取天气信息
    # 返回 {1: WeatherInfo(...), 2: WeatherInfo(...), ...}
```

**步骤 2**：在 Phase2 组装 DailyPlan 时关联天气数据

```python
# 在 plan_trip() 的 Phase1 完成后
weather_by_day = self._parse_weather_data(raw_weather, request.start_date, duration)

# 在 Phase2 组装 DailyPlan 时
daily_plan = DailyPlan(
    day=day_num,
    weather=weather_by_day.get(day_num),  # 关联当天天气
    ...
)
```

**步骤 3**：改造 `WeatherQueryAgent` 的 Prompt，要求输出结构化 JSON

在 `WEATHER_SEARCH_PROMPT` 中增加输出格式要求：

```
搜索完成后，请按以下 JSON 格式输出每天的天气信息：
[
  {
    "date": "2024-10-01",
    "day_weather": "晴",
    "night_weather": "多云",
    "day_temp": 25,
    "night_temp": 15,
    "wind_direction": "北风",
    "wind_power": "3级"
  }
]
```
